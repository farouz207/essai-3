De quoi est constitué le robot ?

🧠
Microcontrôleur
Cerveau du robot

Il traite les données de tous les capteurs et envoie les ordres aux moteurs. C'est lui qui exécute l'algorithme PID et prend toutes les décisions en temps réel.

Programme embarquéBoucle rapideE/S digitales
👁️
Capteurs infrarouges
Suivi de ligne

Disposés sous le châssis, ils émettent et reçoivent des signaux IR. La ligne noire absorbe la lumière — le capteur détecte ainsi où se trouve la ligne par rapport au robot.

Émetteur / récepteur IRRéflexion noire/blancheCalibration

Capteur ultrason
Détection d'obstacles

Mesure la distance des obstacles par émission d'ultrasons. Dès qu'un objet est détecté à moins d'un seuil défini, le mode évitement s'active automatiquement.

Propulsion

Deux moteurs à courant continu assurent la propulsion différentielle. Le driver (pont en H) permet de contrôler vitesse et sens de chaque moteur indépendamment via PWM.

Comment ça fonctionne ?

01

Lecture des capteurs

À chaque cycle, le microcontrôleur lit les capteurs IR (position de la ligne) et le capteur ultrason (distance des obstacles devant lui).

02

Obstacle ou ligne ?

Si la distance mesurée est inférieure au seuil, le mode évitement s'active. Sinon, le robot reste en mode suivi de ligne et calcule l'erreur de trajectoire.

03

Calcul de correction (PID)

L'algorithme PID calcule l'écart entre la position actuelle et la trajectoire cible, puis génère une correction proportionnelle, intégrale et dérivée.

04

Commande des moteurs

La correction est convertie en signaux PWM envoyés au driver. Le moteur gauche accélère ou freine par rapport au droit pour corriger la trajectoire en douceur.

05

Retour à la ligne

Après avoir contourné un obstacle, le robot recherche la ligne et reprend le suivi automatiquement, sans interruption visible.

// Boucle principale — Apex Dynamis

void loop() {
  // Lecture capteurs
  int g = lireIR(GAUCHE);
  int c = lireIR(CENTRE);
  int d = lireIR(DROITE);
  float dist = lireUltrason();

  // Obstacle détecté ?
  if (dist < SEUIL) {
    eviterObstacle();
    return;
  }

  // Calcul erreur de ligne
  float err = erreurLigne(g, c, d);

  // Correction PID
  float cor = PID(err);

  // Appliquer aux moteurs
  setMoteurs(
    VITESSE + cor,
    VITESSE - cor
  );
}

// Algorithme PID
float ePrec = 0, somme = 0;
float PID(float e) {
  somme += e;
  float delta = e - ePrec;
  ePrec = e;
  return Kp*e + Ki*somme + Kd*delta;
}
// L'algorithme clé

Le PID — notre avantage technique

Le PID (Proportionnel-Intégral-Dérivé) est l'algorithme central du robot. Sans lui, le robot zigzaguerait. Avec lui, il suit la ligne avec précision et fluidité. Chaque terme joue un rôle spécifique :

P
Proportionnel
Kp × erreur
Corrige proportionnellement à l'écart actuel. Plus le robot s'éloigne de la ligne, plus la correction est forte et immédiate.
I
Intégral
Ki × Σerreurs
Accumule les erreurs dans le temps. Corrige les dérives progressives et empêche le robot de rester légèrement décalé en permanence.
D
Dérivé
Kd × Δerreur
Prédit et amortit les corrections. Empêche le robot de sur-corriger et d'osciller — le mouvement devient plus fluide et stable.
